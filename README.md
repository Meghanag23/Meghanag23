### Featured projects

<details>
<summary><b>RAG-Enhanced AI Interview Simulator</b> · Python · FastAPI · ChromaDB · Gemini</summary>

<br/>

An AI interview agent for behavioral interview practice. It retrieves role-specific questions, scores each answer against the STAR framework, adapts difficulty as you go, and finishes with a personalized report.

| | |
|---|---|
| **Stack** | Python, FastAPI, SentenceTransformers, ChromaDB, rank-bm25, Gemini API |
| **Retrieval** | Dense semantic search over question embeddings, with a BM25 keyword baseline |
| **Evaluation** | Dense retrieval beat BM25: Precision@3 **0.40 vs 0.27**, MRR **1.00 vs 0.80** |
| **Features** | STAR scoring, adaptive difficulty, session memory, weak-topic tracking, final report |
| **Repository** | [Meghanag23/AI_Interview_Simulator](https://github.com/Meghanag23/AI_Interview_Simulator) |

</details>
