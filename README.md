### 🚀 Featured Projects

#### [RAG-Enhanced AI Interview Simulator](https://github.com/Meghanag23/AI_Interview_Simulator)

AI interview agent that retrieves role-specific behavioral questions with semantic search, scores answers using the STAR framework, adapts difficulty, and generates a personalized report. Dense retrieval beat a BM25 baseline (Precision@3 0.40 vs 0.27).

`Python` `FastAPI` `ChromaDB` `SentenceTransformers` `Gemini API`

#### Behavioral Anomaly Detection (MS thesis, private repo)

Models a home's normal daily routine from IoT sensor events and flags unusual activity, with LLM-generated plain-language alerts.

`Python` `PyTorch` `Transformers` `LLMs`

#### [Smart Household Grocery Tracker](https://github.com/Meghanag23/household_grocery_tracker)

ML pipeline on the Instacart dataset that predicts household reorders and items likely to expire, to cut food waste.

`Python` `Scikit-learn` `Pandas`
